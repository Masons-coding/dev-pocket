Binary, Hex & Decimal Converter

Type a number in any base from 2 to 36 and see it as decimal, hexadecimal, binary and octal. It handles very large integers exactly and accepts 0x, 0b and 0o prefixes.

Why programmers use different bases

Computers store everything as bits (binary). Hexadecimal packs four bits into one digit, so a byte is exactly two hex digits - which is why colours, memory addresses and hashes are written in hex. Octal groups three bits and still appears in Unix file permissions such as 755.

Notes

Negative numbers are shown with a minus sign rather than in two's-complement form. Only whole numbers are supported.

Frequently asked questions

What is 0xFF?

The prefix 0x means hexadecimal; FF is 255 in decimal.

How big a number can I convert?

Very large integers work because the tool uses arbitrary-precision BigInt.

Can I convert fractions?

Not in this tool - integers only.
